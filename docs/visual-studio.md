# Visual Studio

## Visual Studio extensions

If you use Visual Studio, you should install the following extensions.

### Recommended extensions

- [CSharpier](https://marketplace.visualstudio.com/items?itemName=csharpier.CSharpier) -
  Formats C# (and XML) files according to our conventions.
  (For Visual Studio 2019, use [CSharpier 2019](https://marketplace.visualstudio.com/items?itemName=csharpier.CSharpier2019) instead.)
