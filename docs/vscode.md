# Visual Studio Code

## VS Code extensions

If you use Visual Studio Code, you should install the following extensions.

Visual Studio Code will suggest these extensions automatically
(using [.vscode/extensions.json](../.vscode/extensions.json) in the repository root).
If you rather review and/ore install them individually,
you can use the links below.

### Recommended extensions

- [EditorConfig](https://marketplace.visualstudio.com/items?itemName=EditorConfig.EditorConfig) -
  Adds support for the [.editorconfig](https://editorconfig.org/) file.
  This helps ensure consistency of settings such as tabs between editors

- [CSharpier](https://marketplace.visualstudio.com/items?itemName=csharpier.csharpier-vscode) -
  Formats C# (and XML) files according to our conventions

- [markdownlint](https://marketplace.visualstudio.com/items?itemName=DavidAnson.vscode-markdownlint) -
  Markdown linting for repo README.md and other docs

### Helpful extensions (completely optional)

- [Task](https://marketplace.visualstudio.com/items?itemName=task.vscode-task)
  Browse and run tasks from the Taskfile directly from VS Code

- [TODO Tree (for VSCode)](https://marketplace.visualstudio.com/items?itemName=Gruntfuggly.todo-tree) -
  Searching and reviewing comment tags like TODO and FIXME
